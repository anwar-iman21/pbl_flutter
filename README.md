## 📋 Prasyarat

Pastikan sudah terinstal:

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (versi 3.x atau terbaru)
- Dart SDK (sudah termasuk dalam Flutter)
- Android Studio / VS Code
- Emulator Android / perangkat fisik / Google Chrome (untuk web)

Cek instalasi dengan:

```bash
flutter doctor
```

## 🚀 Cara Menjalankan

1. **Clone repository**

   ```bash
   git clone https://github.com/anwar-iman21/pbl_flutter.git
   cd pbl_flutter
   ```

2. **Install dependency**

   ```bash
   flutter pub get
   ```

3. **Jalankan aplikasi**

   ```bash
   flutter run
   ```

   Untuk menjalankan di browser:

   ```bash
   flutter run -d chrome
   ```

## 📦 Build Aplikasi

```bash
# Android (APK)
flutter build apk --release

# Web
flutter build web
```
